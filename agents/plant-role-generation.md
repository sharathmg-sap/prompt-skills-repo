# Plant-based Role Generation (from Master Roles)

## Objective

Create one role per plant from each **master role** by:

1. Substituting the **plant number** into the role name.
2. Building the role description as: `<Plant Name> : <base description>`.

---

## Required Inputs

- **Master roles list** (role name + master description)
  - Examples:
    - `M:0000_SFI_AGL_DSP_FI_DATA`
    - `M:0000_SD_DTS_DSP_ALL`
    - `ZHS:XXXX_DTS_ENT_PHY_INV_CNT_MTN`
    - `CALOR:0000_OTC_CUS_SEV_TL`
- **Plant master data**
  - `Plant number` (4 digits, e.g. `1002`)
  - `Plant name` (e.g. `DSV Air & Sea GmbH`)

---

## Pattern 1 — Role Name (plant substitution)

### Rule

A plant role name is generated by replacing the plant placeholder in the master role with the actual plant number.

**Master role format**

```text
<PREFIX>:<PLANT_PLACEHOLDER>_<ROLE_SUFFIX>
```

**Plant role format**

```text
<PREFIX>:<PLANT_NUMBER>_<ROLE_SUFFIX>
```

Where:

- `<PREFIX>` is `M`, `ZHS`, `CALOR`, etc.
- `<PLANT_PLACEHOLDER>` is typically `0000` or `XXXX`
- `<ROLE_SUFFIX>` remains unchanged

### Replacement rules

- If master role contains `:0000_...` ⇒ replace `0000` with the 4-digit plant number
- If master role contains `:XXXX_...` ⇒ replace `XXXX` with the 4-digit plant number

### Examples

- `M:0000_SFI_AGL_DSP_FI_DATA` → `M:1002_SFI_AGL_DSP_FI_DATA`
- `ZHS:XXXX_DTS_ENT_PHY_INV_CNT_MTN` → `ZHS:1050_DTS_ENT_PHY_INV_CNT_MTN`
- `CALOR:0000_OTC_CUS_SEV_TL` → `CALOR:1010_OTC_CUS_SEV_TL`

---

## Pattern 2 — Role Description (plant name prefix)

### Rule

The plant role description always follows:

```text
<Plant Name> : <base description>
```

### Base description derivation

- If the master description starts with `MASTER:`, remove that prefix and trim spaces.

Example:

- Master: `MASTER: DISPLAY FINANCIAL DOCUMENTS`
- Base: `DISPLAY FINANCIAL DOCUMENTS`

### Separator (strict)

Use exactly:

```text
 : 
```

(space-colon-space)

### Example

- Plant name: `DSV Air & Sea GmbH`
- Base description: `DISPLAY FINANCIAL DOCUMENTS`
- Generated: `DSV Air & Sea GmbH : DISPLAY FINANCIAL DOCUMENTS`

**Inputs**

- Master Role Name: `M:0000_SFI_AGL_DSP_FI_DATA`

**Outputs**

## Validation / Quality Checks

- **Plant number format:** must match `^\d{4}$`.
- **Plant name:** must be present (non-empty).
- **Uniqueness:** generated role names should be unique.
- **Suffix integrity:** only the plant segment (`0000`/`XXXX`) changes; suffix remains unchanged.
- **Description integrity:** master `MASTER:` prefix removed; final format uses ` : ` separator.

## Excel Update (using `skill xlsx`)

### Input (Excel)

An `.xlsx` file containing:

- Master role name
- Master role description
- Plant number
- Plant name

The input may be provided in either of these common layouts:

**Layout A — single sheet (role × plant rows)**  
Each row already contains both the master role and the plant information.

**Layout B — two sheets**
- Sheet 1: master roles (name + description)
- Sheet 2: plants (plant number + plant name)

### Output (Excel)

An updated `.xlsx` where, for each master role, the plant-specific roles are generated and **inserted directly below** the corresponding master role entry (one row per plant), including:

- Generated plant role name
- Generated plant role description

### Generation Rules (recap)

- **Plant role name:** replace the plant placeholder segment in the master role (`0000` or `XXXX`) with the 4-digit plant number.
- **Plant role description:** `<Plant Name> : <base description>`
  - Base description = master description with `MASTER:` removed (if present), then trimmed.

### Required Columns (recommended headers)

To make the automation deterministic, use these headers (case-insensitive is fine):

**Inputs**
- `Master Role Name`
- `Master Role Description`
- `Plant Number`
- `Plant Name`

**Outputs (to be written by the skill)**
- `Plant Role Name`
- `Plant Role Description`

### Row Insertion Behavior

- For each master role row, generate one row per plant and **insert those rows immediately below** the master role row.
- The inserted rows should keep the master role name/description copied (optional) or left blank, but must contain the generated plant role name/description.

### Implementation Instructions (for the `skill xlsx`)

When using the `skill xlsx`, implement the following steps:

1. **Read input workbook**
   - Load the `.xlsx` and locate the sheet(s) containing the required headers.
2. **Parse master roles and plants**
   - If Layout A: treat each row as a (master role, plant) pair.
   - If Layout B: build a Cartesian product of all master roles × all plants.
3. **Generate plant roles**
   - Apply the Role Name and Role Description rules defined above.
4. **Write output**
   - Insert generated plant-role rows directly below each master role (grouped by master role).
   - Populate `Plant Role Name` and `Plant Role Description`.
5. **Save workbook**
   - Save as a new file (do not overwrite input unless explicitly requested).

## Notes

- The same pattern applies across role prefixes (`M`, `ZHS`, `CALOR`, etc.).
- Dynamic per plant:
  - role name plant segment
  - plant name in description
- Everything else is inherited from the master template.
